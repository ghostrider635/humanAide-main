## 📌 Objectif du projet

HumanAide est un site web caritatif qui vise à aider les personnes vulnérables, en particulier les orphelins.
Le projet permet de sensibiliser le public, d'organiser des événements solidaires et de recevoir des dons grâce à une interface simple et accessible.

      Le site comprend plusieurs pages comme :

      Accueil

      Causes soutenues

      Événements

      Galerie

      Contact

Fonctionnalités
Menu responsive compatible mobile (hamburger menu)

Formulaire de contact connecté avec EmailJS

Présentation des causes humanitaires

Mise en avant des événements à venir

Galerie d’images des actions réalisées

Boutons d'appel au don (simulé)

## 🛠️ Technologies utilisées

- Langage principal : `html` / `JavaScript` / `css`
- Outils : `GitHub`, `Emailjs`, `google form`
